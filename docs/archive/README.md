# Archive

Analyses and plans written before the backend was hardened (milestones M1 to M13). They are kept for history
and describe the system as it was then: one Redis, results on disk, jobs that could be lost between the
database and the queue. Do not read them as a description of the system today.

The current design is in [../TARGET_ARCHITECTURE.md](../TARGET_ARCHITECTURE.md), and the repository's
[README](../../README.md) is the place to start.
